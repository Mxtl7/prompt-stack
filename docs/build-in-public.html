🛠 Cómo actualizar este panel

Es un archivo HTML estático de una sola pieza: sin backend, sin base de datos, sin build. Se edita a mano.

1 · Cambiar cualquier número (sobre todo los ingresos)
  1. Abre docs/build-in-public.html en un editor de texto.
  2. Busca el bloque const BIP = { ... }; justo debajo de <body>.
  3. Edita el valor que quieras. Ejemplo: ingresosUSD: 14.29, cuando caiga la primera venta neta.
  4. Actualiza actualizado: "2026-10-12" con la fecha de hoy.
  5. Guarda. Recarga la página en el navegador. Listo.
2 · Añadir un bounty a la tabla
  1. Dentro de BIP.bounties = [ ... ] copia una línea { ... } existente.
  2. Rellena nombre, plataforma, monto, estado y fase.
  3. En fase usa una de: en curso, en revisión, listo para enviar, bloqueado, cerrado — define el color del chip.
3 · Añadir un hito al timeline
  1. En BIP.hitos = [ ... ] añade { fecha, titulo, texto } al principio de la lista (el más reciente primero, o al final si prefieres orden cronológico).
  2. Para un hito futuro/pendiente añade pendiente: true y se dibujará con el punto hueco.
4 · Publicar (sólo cuando lo decidas tú)
  1. Esta página no se sube sola. El commit/push lo haces tú.
  2. Opcional: enlázala desde docs/index.html (un link "Build in public" en el footer) y añádela a docs/sitemap.xml para que los buscadores la descubran.
  3. Vive en: https://mxtl7.github.io/prompt-stack/build-in-public.html
