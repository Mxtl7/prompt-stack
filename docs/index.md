## 🏆 Why this stack is different

Most prompt packs are a dump of one-line snippets. This is a documented operating system for your freelance business:

- 🛡 **Anti-hallucination built in** — every prompt forces the AI to mark unverified claims with `[VERIFY]` / `[CONFIRM]` instead of inventing facts, prices, or quotes. The difference between a tool and a liability.
- 🧩 **Real system prompts** — each prompt sets the AI's role, constraints, and a structured output spec, so you get consistent, professional-grade output — not a lucky guess.
- 🔧 **Customization slots** — `[brackets]` for your service, niche, prospect, and rate. Adapt any system to your business in under a minute.
- 🌎 **A real LatAm Spanish edition** — market-adapted examples and channels, not a machine translation.
- 💼 **The full money path** — find work (01, 11, 20), win it (03, 07, 16), deliver it (09, 10, 18, 19), market it (02, 04, 05, 06, 12–15, 17).
- ⚡ **Universal format** — plain `.md` files that work in any AI tool. Copy, fill the brackets, paste. MIT license.

## ❓ FAQ

**How do I use the prompts?**
Open any `.md` file, copy the prompt, replace the `[brackets]` with your details, and paste it into ChatGPT, Claude, Gemini, or any AI tool. Adjust the output until it sounds like you.

**Do I need an app or a subscription?**
No. These are plain `.md` files that work in any AI tool you already use — nothing to install, nothing to keep paying for.

**What makes these different from free prompt lists?**
Free lists give you 1000 snippets you never use. Each of these is a *system*: a system instruction that sets the AI's role, a structured output spec, and customization parameters — plus `[VERIFY]` flags that stop the AI from inventing facts. You get 20 documented systems you'll actually run every week.
