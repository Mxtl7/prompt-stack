Two capture surfaces into the same list

On-page form EXISTING

On free-samples.html (the #weekly section) and linked from the hero + nav. Posts to Formspree, falls back to mailto:. Converts readers who finish the 3 samples.

Exit-intent pop NEW

Fires when a visitor moves to leave (desktop: cursor to the top edge; touch: scroll-depth/time). Offers the FIRST10 code to recover the abandoning visitor. Same endpoint, same sequence, adds a source=exit-intent tag.

Nurture = retargeting on an owned channel ($0)

Every captured email enters the one sequence. There is no separate "retargeting" tool — the emails are the retargeting. Email is the only re-touch channel (owned, free); paid ad-retargeting via a pixel is explicitly out of scope for v1.

Worked example (1,000 visits): 1,000 × 2–5% → 20–50 leads; 20–50 × 1–3% → ≈ 0.2–1.5 buyers; at $9.99–$14.99 → ≈ $2–$22. Exit-intent lifts the first number (more of the same traffic is captured), so it compounds through the whole funnel. It does not change lead→sale; only the offer/sequence does.
