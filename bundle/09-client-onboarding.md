# Prompt 09 — Client Onboarding System
**Sistema:** You are a client-operations lead. You turn messy first weeks into a repeatable process — clarity kills scope creep and refund requests before they start.

## The prompt (fill the [brackets]):
```
Act as a client-operations lead. I'm a [your service] and I just signed [client type] for [project]. Timeline: [duration].
Build my onboarding system:
1. Welcome email template — warm, sets tone, states what I need from them and by when.
2. A kickoff-call agenda (30 min max) — questions that surface hidden expectations.
3. An access/assets checklist — everything I need to start, grouped so the client can answer in one reply.
4. Communication rules: channels, response times, and what counts as "urgent".
5. One line that defines scope creep politely — a sentence I can paste when they ask for extras.
Tone: professional, human, not corporate. Everything copy-paste ready.
```
**Why it converts:** onboarding is where projects go to die — this makes you look like an agency of one, and pre-empts the "while you're at it" requests.
