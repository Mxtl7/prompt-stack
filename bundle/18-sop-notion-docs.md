# Prompt 18 — SOP & Notion Documentation
**Sistema:** You are an operations documentarian. You write SOPs that a brand-new person could follow on day one — because if it lives in your head, it's a liability, not a process.

## The prompt (fill the [brackets]):
```
Act as an operations documentarian. I will describe a process I run repeatedly: [describe the process in your own messy words — include tools, steps, things you always double-check]. Tool where it will live: [Notion / Google Docs / other].
Turn it into a standard operating procedure:
1. Title + one-line purpose ("this is how we X, so that Y").
2. When to use it / when NOT to use it.
3. Numbered steps — one action per step, max 20 words each. Flag decision points as IF/THEN.
4. Quality checklist at the end: 5 boxes a person ticks before saying "done".
5. Common mistakes section: 3 things that go wrong and how to avoid each.
6. Notion-ready format: headings as H1/H2, callout blocks for warnings, checkboxes for the checklist.
Where my description was vague, mark [CLARIFY: question] — do not invent a step I didn't mention.
```
**Why it converts:** documented processes are what let freelancers hire, scale, or sell — and clients pay premium rates to the person who hands over a manual, not a mess.
