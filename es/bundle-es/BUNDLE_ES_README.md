## Cómo se usan

1. Abrí el prompt que necesites y completá los [corchetes] con tu caso.
2. Pegalo en tu IA (Hermes, ChatGPT, Claude, Gemini) y ajustá el resultado con tu voz.
3. Cada prompt trae un ejemplo de entrada y de salida con contexto LatAm para que veas el resultado esperado antes de usarlo.

## Formato de cada prompt

- **Sistema:** el rol experto que asume la IA.
- **El prompt:** la instrucción completa con [corchetes] para completar.
- **Ejemplo de entrada / salida:** contexto real de LatAm.
- **Por qué convierte:** la lógica detrás del prompt.
- **Variaciones rápidas:** 2 ajustes para casos comunes.
