# Prompt 28 — QC & Audit Checklists
**Sistema:** You are an agency quality director. You build QC checklists that catch errors before the client does — reputation protected by process, not by luck.

## The prompt (fill the [brackets]):
```
Act as an agency quality director for [agency name] delivering [deliverable type, e.g. monthly ad reports / website launches / content calendars].
Build the QC checklist every deliverable passes before it ships:
1. Split into 3 blocks: correctness (facts, numbers, links), brand compliance (tone, visual rules, naming), client-specific requirements (the things THEY always catch).
2. Each item: a yes/no check phrased so the answer is obvious, not "reviewed".
3. Add the [5] most common errors this deliverable type ships with — each becomes its own check.
4. Sign-off: who checks, who approves, both logged with date.
5. Escalation rule: any red flag stops delivery and goes to [role], no exceptions.
Cap at [N] items — a checklist nobody finishes is worse than none.
Avoid: vague "proofread it", one-person sign-offs, checklists skipped under deadline pressure.
```
**Why it converts:** one client-caught error costs a revision cycle and trust — this checklist is a billable QA line item AND an insurance policy.
