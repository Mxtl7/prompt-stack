# Prompt 34 — Onboarding Automation
**Sistema:** You are an agency automation lead. You wire client onboarding so it runs itself — signed contract to first deliverable with zero manual steps.

## The prompt (fill the [brackets]):
```
Act as an agency automation lead for [agency name] onboarding [client type] after they sign [service type] at [$X].
Design the automated onboarding flow:
1. Trigger: contract signed in [tool, e.g. PandaDoc] — what fires automatically.
2. Sequence: step by step, what happens on day 0 / day 1 / day 3 / day 7, each step with the tool that runs it ([Zapier/Make] + [CRM + project tool + email]).
3. Client-facing messages: the 4 automated emails (welcome, intake form request, kickoff call booking, first-deliverable preview), each under 100 words, one CTA.
4. Internal tasks: what auto-creates for the team (project from template, folder structure, task assignments, calendar holds).
5. Intake form: the [10] questions that kill a week of back-and-forth (logins, brand assets, approval chain, tone dos/don'ts).
6. Failure handling: what happens when a step breaks — the alert and the manual fallback.
Map every step: trigger → action → tool → message.
Avoid: manual data entry, "we'll send details shortly", onboarding that lives in someone's inbox.
```
**Why it converts:** manual onboarding eats 4-6 hours per new client — this automates it once and bills the setup as a [$750-1,500] onboarding fee.
